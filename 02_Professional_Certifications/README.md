# 02. Professional Certifications Repository

Comprehensive evaluation and guides for high-leverage industry, academic, and vendor credentials following the canonical 9-section certification template.

- **[Master Domain & Exam Codes Catalog](Domain_Grouped_Certifications_and_Codes.md)**: Full breakdown of every certification by technical domain, official exam codes, difficulty (1-10), cost, and career mapping.

## Categorization:
- **`Computer_Science/`**:
  - `Cloud_Computing/`: AWS Solutions Architect (SAA-C03), Azure Solutions Architect Expert (AZ-305), GCP Professional Cloud Architect (GCP-PCA).
  - `Cybersecurity/`: CompTIA Security+ (SY0-701), CySA+ (CS0-003), PenTest+ (PT0-002), CEH (312-50), OSCP (PEN-200), CISSP (CISSP-CAT).
  - `Networking/`: Cisco CCNA (200-301), CCNP Enterprise (350-401 ENCOR), CompTIA Network+ (N10-009).
  - `Artificial_Intelligence/`: TensorFlow Developer Certificate (TF-DEV), DeepLearning.AI GenAI Professional (DL-GENAI-PRO).
  - `Machine_Learning/`: AWS Certified Machine Learning Specialty (MLS-C01).
  - `DevOps/`: Certified Kubernetes Administrator (CKA), HashiCorp Terraform Associate (TA-003).
  - `Operating_Systems/`: Red Hat Certified System Administrator (EX200 / RHCSA).
  - `Programming/`: Oracle Java SE Developer (1Z0-829), Python Institute PCAP (PCAP-31-03).
  - `Database/`: MongoDB Certified Developer Associate (C100DEV).
- **`Vendor_Certifications/`**: Cross-referenced directories for Cisco, Microsoft, AWS, Google, CompTIA, Red Hat, Oracle.
- **`Academic_Certifications/`**: NPTEL Elite Gold Domain Scholars (NPTEL-GOLD), SWAYAM Credit Transfer (SWAYAM-UGC), University Credentials.
- **`Other_Professional_Certifications/`**: Project Management Professional (PMP-ECO), Chartered Financial Analyst (CFA-L123).

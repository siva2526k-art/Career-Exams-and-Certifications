# 02. Professional Certifications Repository

Comprehensive evaluation and guides for high-leverage industry, academic, and vendor credentials following the canonical 9-section certification template.

## Categorization:
- **`Computer_Science/`**:
  - `Cloud_Computing/`: AWS Solutions Architect, Azure Solutions Architect Expert, GCP Professional Cloud Architect.
  - `Cybersecurity/`: CompTIA Security+, CySA+, PenTest+, CEH, OSCP, CISSP.
  - `Networking/`: Cisco CCNA, CCNP Enterprise, CompTIA Network+.
  - `Artificial_Intelligence/`: TensorFlow Developer Certificate, DeepLearning.AI GenAI Professional.
  - `Machine_Learning/`: AWS Certified Machine Learning Specialty.
  - `DevOps/`: Certified Kubernetes Administrator (CKA), HashiCorp Terraform Associate.
  - `Operating_Systems/`: Red Hat Certified System Administrator (RHCSA).
  - `Programming/`: Oracle Java SE Developer, Python Institute PCAP.
  - `Database/`: MongoDB Certified Developer Associate.
- **`Vendor_Certifications/`**: Cross-referenced directories for Cisco, Microsoft, AWS, Google, CompTIA, Red Hat, Oracle.
- **`Academic_Certifications/`**: NPTEL Elite Gold Domain Scholars, SWAYAM Credit Transfer, University Credentials.
- **`Other_Professional_Certifications/`**: Project Management Professional (PMP), Chartered Financial Analyst (CFA).

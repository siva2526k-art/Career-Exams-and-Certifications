# 08. Canonical Document Templates

Standardized templates ensuring absolute data consistency across all contributions:
- **`Exam_Template.md`**: Mandatory 11-section structure for all competitive examinations.
- **`Certification_Template.md`**: Mandatory 9-section rubric for all professional certifications.
- **`Career_Template.md`**: Standard structure for career pathways and pay bands.
- **`Organization_Template.md`**: Standard profile structure for conducting authorities.

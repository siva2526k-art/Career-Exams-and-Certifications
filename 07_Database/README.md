# 07. Machine-Readable Relational JSON Database

Structured JSON datasets maintaining the single source of truth for the repository:
- **`exams.json`**: 44 structured competitive examination records.
- **`certifications.json`**: 25 structured professional certification records.
- **`organizations.json`**: 37 verified conducting organizations and accredited vendors.
- **`careers.json`**: 11 mapped career trajectories and pay scales.
- **`sources.json`**: 35 canonical official URLs and gazette sources.

*Validated automatically by `10_Automation/scripts/validate_database.py`.*

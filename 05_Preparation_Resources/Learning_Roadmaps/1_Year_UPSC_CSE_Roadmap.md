# 1-Year Strategic Master Roadmap: UPSC Civil Services Examination

> **A disciplined 365-day integrated preparation blueprint balancing General Studies (Prelims + Mains), Optional Subject, CSAT, and Current Affairs.**

```
┌────────────────────────────────────────────────────────────────────────┐
│ Month 1-3: NCERT Foundations & Optional Subject Phase 1                │
│ - Complete Class 6-12 NCERTs (History, Geo, Polity, Economy)           │
│ - Finish 50% of chosen Optional Subject syllabus                       │
│ - Daily 1 Hour: The Hindu / Indian Express analytical reading          │
├────────────────────────────────────────────────────────────────────────┤
│ Month 4-6: Standard Reference Texts & Optional Subject Completion      │
│ - Laxmikanth (Polity), Spectrum (Modern History), Shankar (Env)        │
│ - Finish remaining 50% of Optional Subject + Start PYQ answer writing  │
│ - CSAT weekly practice (Quant + Reading Comprehension)                 │
├────────────────────────────────────────────────────────────────────────┤
│ Month 7-9: Integrated Mains Answer Writing & Ethics (GS IV)            │
│ - Complete GS Paper IV (Ethics case studies) & Essay practice          │
│ - Sectional Mains Answer Writing tests (GS 1, 2, 3)                     │
│ - Consolidate micro-notes on current socio-economic issues             │
├────────────────────────────────────────────────────────────────────────┤
│ Month 10-11: Dedicated Prelims Mode (100% Focus)                       │
│ - Solve 40-50 Full-Length Prelims Mock Tests (GS Paper 1 + CSAT)       │
│ - Intensive revision of Year-round Current Affairs Compilations        │
│ - Memorize high-yield factual charts (National Parks, Treaties, Maps)  │
├────────────────────────────────────────────────────────────────────────┤
│ Month 12: Final Sprint & Exam Simulation                               │
│ - Strict timed exam simulation in 9:30-11:30 and 14:30-16:30 slots     │
│ - Final formula sheets, constitutional articles, and map revisions    │
└────────────────────────────────────────────────────────────────────────┘
```

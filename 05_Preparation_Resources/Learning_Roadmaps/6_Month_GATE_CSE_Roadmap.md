# 6-Month Strategic Roadmap: GATE Computer Science & Information Technology

> **Phase-wise, week-by-week preparation blueprint designed for aspirants targeting an All India Rank (AIR) within top 100.**

## Phase 1: Mathematical Foundations & Core Programming (Months 1 & 2)
- **Engineering Mathematics:** Linear Algebra (Eigenvalues, Matrices), Calculus, Probability & Statistics (Bayes Theorem, Distributions).
- **Discrete Mathematics:** Propositional and First-Order Logic, Set Theory, Combinatorics, Graph Theory, Recurrence Relations.
- **Programming & Data Structures:** C programming language intricacies (pointers, recursion), Arrays, Stacks, Queues, Linked Lists, Trees, Binary Search Trees, Heaps, and Hashing.

## Phase 2: System Software & Architecture (Months 3 & 4)
- **Algorithms:** Asymptotic notation, Divide and Conquer, Greedy Algorithms, Dynamic Programming, Graph Traversals (BFS/DFS, Dijkstra, Bellman-Ford).
- **Theory of Computation:** Regular languages, Finite Automata (DFA/NFA), Context-Free Grammars, Pushdown Automata, Turing Machines, Decidability.
- **Compiler Design:** Lexical analysis, Parsing (LL, LR, LALR), Syntax-Directed Translation, Intermediate Code Generation.
- **Operating Systems:** Process management, Threads, CPU Scheduling, Deadlock prevention/avoidance, Memory management (Paging, Virtual Memory), File systems.

## Phase 3: Hardware, Networking & Databases (Month 5)
- **Computer Organization and Architecture:** Machine instructions, Addressing modes, ALU, Data-path and Control unit, Pipelining (hazards, stalls), Memory hierarchy (Cache mapping, Miss rates).
- **Databases (DBMS):** ER-model, Relational model (Relational Algebra, Tuple Calculus), SQL queries, Normalization (1NF to BCNF), Transaction processing and Concurrency control.
- **Computer Networks:** ISO/OSI & TCP/IP stack, Data link layer (Framing, Error control, Flow control), Routing algorithms (Distance Vector, Link State), IPv4/IPv6, Transport layer (TCP sliding window, UDP), Network security fundamentals.

## Phase 4: Full-Length Mocks & Intensive Revision (Month 6)
- **Previous Year Questions (PYQs):** Solve all 30 years of GATE CSE question papers in timed 3-hour exam conditions.
- **Full-Length Mock Series:** Take at least 15-20 full-length mocks from reputable test series.
- **Error Log & Formula Revision:** Maintain a strict daily log of conceptual errors, unforced calculation mistakes, and formula sheets.
